DAYLIGHT CAFE WEBSITE

Files:
- index.html             Main / welcome page with image slider
- menu.html              Menu with prices and Add to cart buttons
- checkout.html          Cart with quantity controls and order confirmation
- contact.html           About Us and Contact Us page
- cafestyle.css          Shared styling
- cafe.js                Navigation, sliders, cart, and form behaviour
- cafe-logo.webp         Your original uploaded cafe storefront image
- pasta.jpg              Generated food photograph
- coffee.jpg             Generated coffee photograph
- donuts.jpg             Generated pastry photograph
- bread.jpg              Generated bakery photograph
- cafe-interior.jpg      Generated cafe interior photograph
- coffee-dessert.jpg     Generated cafe table photograph
- generated-cafe-collage.png  Original six-panel generated image

How to run:
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a browser or use VS Code Live Server.
4. Add items from Menu; they appear in Checkout using browser localStorage.

All cafe photographs used by the website are now stored locally in this folder.
Google Fonts still use an online font service; if offline, the site falls back to system fonts.

Notes:
- Contact details are sample placeholders. Replace them with real cafe details.
- This is a front-end demo: the contact form does not send email and checkout does not process real payments.
